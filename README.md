# 사각사각

아이패드와 Apple Pencil을 위한 A4 필사 게시판. Node.js 24 이상만 필요하며 외부 패키지는 없습니다.

```sh
npm start
```

기본 포트는 3000이며 `PORT`로 변경할 수 있습니다. SQLite DB는 `data/site.sqlite`에 자동 생성됩니다. `DB_PATH`로 다른 DB 파일을 지정할 수 있습니다. 배포할 때는 DB 디렉터리를 영구 볼륨으로 연결하고 백업하세요. HTTPS를 제공하는 Node.js 호스팅이 필요합니다. 정적 GitHub Pages만으로 서버 및 공유 저장 기능을 실행할 수 없습니다.

## 제공 기능

- A4 비율 필기, 펜 굵기·잉크, 필압, 지우개, 되돌리기, 기기 임시 원고 저장
- 자유 글감 / 자체 작성한 제공 글감 3개
- 공개 작품 게시판, 별점과 댓글, 주간·월간 대표작
- 한국 시간 월요일 0시 / 매월 1일 0시 이후 게시된 작품의 누적 평균 별점으로 순위 산정. 동점은 평가 수, 최신순. 대표작은 평가가 있는 작품에서 선정
- 로그인 없는 필명 참여, 브라우저 식별자로 작품당 평가 1회 제한

## 검증

```sh
npm test
node --check server.mjs
node --check public/app.js
```

실제 iPad에서 Apple Pencil 필압, 손바닥 터치, 스크롤을 확인해야 합니다. ‘Apple Pencil만 필기’ 옵션으로 손가락은 스크롤에 사용할 수 있습니다.

## 공개 운영 전 남은 사항

현재는 실행 가능한 초기 버전입니다. 브라우저 저장소를 초기화하면 평가 제한을 우회할 수 있습니다. 공개 운영에는 인증·서버 기반 중복 평가 제한, 신고/삭제·운영자 기능, 개인정보 안내와 데이터 백업 정책을 추가하는 것이 권장됩니다. 현재 게시 후 수정·삭제 UI는 없습니다. 저작권이 허용되는 글만 게시하세요.
